== Limits at a glance

[cols="2,4",options="header"]
|===
|Limit |Value

|Request and follow-up text
|500 characters

|Provider scope (subscription, project, account, compartment)
|1024 characters

|Support message
|500 characters

|Generate-and-validate attempts per request
|5 in the shipped `config.yaml` (`orchestration.max_validation_iteration`)

|Drift check inside a generate round
|2 passes

|Drift remediation session
|3 iterations (`orchestration.max_drift_reports`)

|One operation per session at a time
|A second request while one is running is ignored until it finishes

|Live progress stream
|About 3 hours per connection; reopen the session afterwards

|xref:main:reference/roles-and-permissions.adoc[Roles]
|`developer`: generate, pull request, apply. `devops`: also drift
remediation.
|===
