= Guides
:description: Task guides for using, reviewing, customizing, deploying, and developing Kumoss, grouped by what you want to do.

These guides show how to accomplish specific tasks with Kumoss. Pick the
group that matches your role, then the guide that states your goal. To
watch the main guides play out in one real session, see
xref:main:see-it-in-action.adoc[See Kumoss in action].

== Use Kumoss

For developers who ask Kumoss for infrastructure changes.

[cards,columns="1 s:2 m:3"]
====
[card]
.xref:main:guides/make-a-request.adoc[Make a request]
Open a session and phrase a request the filter accepts.

[card]
.xref:main:guides/follow-a-session.adoc[Follow a session]
Track progress and read the report, plan, and code.

[card]
.xref:main:guides/merge-and-apply.adoc[Merge and apply]
Open, merge, and apply the pull request of a session.

[card]
.xref:main:guides/resolve-a-locked-session.adoc[Resolve a locked session]
Find out why a session is locked and get it unlocked.
====

== Operating modes

What each kind of session does, from the request to the merge. For the
three side by side, see
xref:main:reference/operating-modes.adoc[Operating modes].

[cards,columns="1 s:2 m:3"]
====
[card]
.xref:main:guides/generate-infrastructure.adoc[Generate infrastructure]
Turn a request into validated Terraform code, reviewed as a plan and
report before you apply it.

[card]
.xref:main:guides/remediate-drift.adoc[Remediate drift]
Detect and reconcile drift for a set of resources or a whole Terraform
root.

[card]
.xref:main:guides/import-infrastructure.adoc[Import infrastructure]
Bring existing, unmanaged cloud resources under Terraform management,
for a specific set of resources or across a whole scope.
====

== Deploy and operate

For operators who install and run Kumoss.

[cards,columns="1 s:2 m:3"]
====
[card]
.xref:main:guides/deploy-to-production.adoc[Deploy to production]
Plan a production deployment, then work through
xref:main:guides/production/secrets-and-credentials.adoc[secrets and
credentials],
xref:main:guides/production/networking-and-tls.adoc[networking and TLS],
xref:main:guides/production/hardening.adoc[hardening], and
xref:main:guides/production/operations.adoc[operations].

[card]
.xref:main:guides/deploy-with-helm.adoc[Deploy with Helm]
Install Kumoss on Kubernetes with the bundled chart, try it on a local
kind cluster, and bind cloud credentials through workload identity.

[card]
.xref:main:guides/enable-authentication.adoc[Enable authentication]
Connect an OIDC identity provider and grant the first administrator
access.

[card]
.xref:main:guides/configure-state-backends.adoc[Configure state backends]
Choose who owns Terraform and OpenTofu state:
xref:main:guides/state-backends/repository-declared.adoc[the repository],
xref:main:guides/state-backends/kumoss-managed.adoc[Kumoss], or
xref:main:guides/state-backends/sidecar-supplied.adoc[the deployment].

[card]
.xref:main:guides/monitor-with-langfuse.adoc[Monitor with Langfuse]
Read Kumoss's traces in Langfuse, and know what a trace contains and
omits.
====

Before upgrading an existing deployment, read
xref:main:guides/upgrade-notes.adoc[Upgrade notes].
