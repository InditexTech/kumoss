A flag on the session that blocks apply and pull-request merge. It is set
automatically at the end of a generate round when the compliance policy
denies the plan (or cannot be evaluated), when the LLM compliance audit
finds an `error` or `critical` violation such as `scope_exceeded`, or,
where the deployment enables it, when the impact is High, and cleared either by an admin-panel
editor or by a later generate round whose audit passes without a
high-impact verdict. Some internal material calls this a plan lock.
